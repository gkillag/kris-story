ЗВУКОВЫЕ ЭФФЕКТЫ (SFX)
======================

Сюда кладём короткие звуки для интерактива.

ТРЕБОВАНИЯ:
- Формат: MP3 или WAV
- Длина: 50-500 мс (очень короткие!)
- Вес: до 50 КБ на файл
- Название: латиницей, без пробелов

НАЗВАНИЯ ФАЙЛОВ (пример):
- click.mp3       — клик по кнопке
- catch.mp3       — поймал сердечко
- flip.mp3        — переворот карточки
- unlock.mp3      — открытие замка
- celebrate.mp3   — салют
- typing.mp3      — один символ печати

КАК ПОДКЛЮЧИТЬ:
Сейчас звук печати и клики синтезируются через Web Audio API.
Если хочешь свой семпл — замени в js/audio.js функцию playTypingSound()
на воспроизведение файла:
  const audio = new Audio('assets/sfx/typing.mp3');
  audio.volume = getEffectiveVolume('typing');
  audio.play();

ПОКА ПАПКА ПУСТАЯ — звуки синтезированные.
