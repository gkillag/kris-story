МУЗЫКА
======

Сюда кладём фоновые треки для новеллы.

ТРЕБОВАНИЯ:
- Формат: MP3 (для совместимости со всеми браузерами)
- Битрейт: 128-192 kbps (больше — тяжелее, не нужно)
- Длина: 30 секунд — 3 минуты
- Вес: 500 КБ — 3 МБ на файл
- Название: латиницей, без пробелов

НАЗВАНИЯ ФАЙЛОВ (пример):
- menu_theme.mp3     — музыка главного меню
- sad_theme.mp3      — грустная тема
- happy_theme.mp3    — радостная тема
- credits_theme.mp3  — на титрах

КАК ПОДКЛЮЧИТЬ:
Сейчас у нас синтезированная шкатулка через Web Audio API.
Когда будет свой трек — в js/audio.js найти функцию playMelody()
и заменить на воспроизведение файла:
  const audio = new Audio('assets/music/menu_theme.mp3');
  audio.volume = getEffectiveVolume('music');
  audio.loop = true;
  audio.play();

ПОКА ПАПКА ПУСТАЯ — играет синтезированная мелодия.
