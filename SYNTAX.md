# 📖 Методичка: синтаксис сценариев KRIS STORY

Файл сценария — обычный текст UTF-8 (`data/script.txt`). Парсер (`js/parser.js`)
превращает его в массив сцен, движок (`js/scenes.js`) проигрывает их как визуальную новеллу.

---

## 1. Базовые правила

| Запись | Что делает |
|---|---|
| `Имя: текст` | Реплика персонажа (имя показывается над текстом) |
| `обычная строка` | Реплика рассказчика (без имени) |
| **пустая строка** | Разделитель сцен: текст до и после — разные «экраны» |
| `# комментарий` | Игнорируется парсером |
| `// комментарий` | То же, другой стиль |

```
Мастер: Я ждал тебя.

Ты заходишь в тёмный шатёр.
Внутри пахнет воском.        ← эти две строки — ОДНА сцена (нет пустой строки)
```

⚠️ Двоеточие считается «репликой персонажа», только если стоит в первых 30 символах строки.

---

## 2. Склейка и переносы строк

| Команда | Действие |
|---|---|
| `@ns` | Перенос строки внутри предыдущей реплики (следующая строка начнётся с новой линии того же экрана) |
| `@cont` | Следующая строка присоединяется к предыдущей реплике **через пробел** (без переноса и без новой сцены) |

```
Мастер: Тот, кто покажет тебе историю.
@ns
Твою историю.                  ← тот же экран, новая строка текста

Длинная мысль начинается тут
@cont
и продолжается здесь одним предложением.
```

---

## 3. Визуальные команды

Все команды пишутся **с отдельной строки**, начинаются с `@`.
Команды «прилипают» к следующей сцене с текстом (или исполняются сами по себе).

| Команда | Аргументы | Действие |
|---|---|---|
| `@char` | `kriss-happy fade` | Показать спрайт `assets/sprites/<имя>.png`; вход: `left` / `right` / `fade` |
| `@char` | `none` | Спрятать спрайт |
| `@bg` | `tent-dark` | Фон `assets/bg/<имя>.jpg` |
| `@fx` | `fog flicker dust rain` | CSS-эффекты (можно несколько через пробел) |
| `@fx` | `none` | Убрать все эффекты |
| `@flash` | `white` или `blood` | Вспышка экрана |
| `@music` | `sad-theme` | Трек `assets/music/<имя>.mp3`; `none` — стоп |
| `@sfx` | `door-creak` | Звук `assets/sfx/<имя>.mp3` |
| `@wait` | `2000` | Пауза в мс перед появлением подсказки «▼» |

Если PNG спрайта нет — движок сам подставит fallback-эмодзи 🎭; фоны рисуются градиентами.

## 4. Переменные (`@var`) и подстановка `{...}`

```
@var trust = 0              ← число или строка: @var name = "Крисс"
@var trust += 1             ← прибавить
@var trust -= 1             ← отнять
```

- Все переменные живут **в рамках одного прогона** (сбрасываются при старте главы).
- Подставить значение в текст можно где угодно фигурными скобками:

```
Мастер: У тебя доверия на {trust} очков, {name}.
```

Работает в репликах персонажей, у рассказчика и в вариантах выбора `?`.
Неизвестная переменная → пустая строка.

## 5. Выборы и ветвление

```
Мастер: Готова узнать правду?

? Да, говори                ← вариант 1 (кнопка)
? Нет, не сейчас            ← варианты привязываются к предыдущему тексту

@if choice == "Да, говори"   ← choice = текст НАЖАТОЙ кнопки
Мастер: Тогда слушай.
@var trust += 1              ← внутри ветки выполняется лениво (только если ветка активна)

@if trust >= 1               ← вложенные ветки разрешены
Мастер: Вижу, ты мне доверяешь.
@endif

@else                        ← иначе (по любой из причин выше)
Мастер: Возвращайся позже.
@endif

Продолжение для всех.        ← сюда приходят из обеих веток
```

Операторы условия: `==` `!=` `>` `>=` `<` `<=`.
Слева — `choice` или имя переменной; справа — строка **в кавычках** или число.
Блоки `@if ... @endif` можно вкладывать друг в друга; `@else` обязателен нет.

## 6. Управление показом (`! директивы`)

Пишутся с `!` с отдельной строки, относятся к следующей сцене:

| Директива | Действие |
|---|---|
| `! skip` | Экран показывается мгновенно, без печати по буквам |
| `! auto 2500` | Следующий экран открывается сам через 2500 мс (тап отменяет) |
| `! speed 25` | Скорость печати этой сцены — 25 мс/символ (меньше = быстрее) |

Также в UI прогона есть кнопки: ⏸ пауза, ▶▶ автопрокрутка, ✕ выход в меню.

## 7. Разметка внутри текста

| Запись | Результат |
|---|---|
| `*слово*` | **жирный** |
| `~слово~` | *курсив* |
| `_слово_` | подчёркнутый |
| `[red]текст[/red]` или `[red]текст[/]` | красный цвет |
| `[gold]текст[/gold]` | золотой цвет |
| `[k]что угодно[/k]` | заменяется на имя игрока из CONFIG (`herName`) |
| `{переменная}` | подстановка значения `@var` |

Разметка не ломает эффект печати: теги «вживляются» целиком в нужный момент.

## 8. Полный пример главы

```
# ГЛАВА 2: Прометей
// Глава о доверии. Требует: trust >= 1 из главы 1

@var chapter2 = 1
@bg tent-dark
@fx fog flicker
@music sad-theme
@char kriss-happy fade

Ты возвращаешься в шатёр на закате.

Мастер: {*Знал*, что придёшь}, {k}.
У тебя доверия: {trust}.

@if trust >= 1
! speed 30
Мастер: Тогда держи ключ.
@sfx unlock
@flash gold

? Взять ключ
? Спросить зачем

@if choice == "Взять ключ"
@var key = "взят"
Ты прячешь ключ в карман.

@else
@var key = "не взят"
Мастер усмехается: ~Любопытство — тоже валюта.~

@endif

Ключ: {key}.
@endif

! auto 2000
Свеча догорает. Продолжение следует...
```

## 9. Частые ошибки

| Симптом | Причина / решение |
|---|---|
| «не закрыт блок @if» | Забыт `@endif` — посчитайте открывающие/закрывающие |
| `@else без открытого @if` | Лишний `@else` или опечатка в `@if` |
| Текст слип в один экран | Нет пустой строки между сценами |
| `{trust}` виден буквально | Такого `@var` нет — подставится пусто; проверьте имя |
| Кавычки в `@if` обязательны | `@if name == Крисс` — ошибка, пишите `"Крисс"` |
| Ошибки парсера | Смотрятся в консоли браузера (`console.warn`, префикс `[parser]`) |

Ошибки синтаксиса не роняют игру — парсер пишет предупреждения в консоль и продолжает.

## 10. Шпаргалка

```
# //          комментарии
Пустая строка = новый экран
Имя: текст    реплика          текст      рассказчик
@ns  @cont    перенос / склейка
@char @bg @fx @flash @music @sfx @wait
@var x = 5 | x += 1 | x -= 1 ; подстановка {x}
? вариант ; @if choice == "..." / @if x >= 2 ; @else ; @endif (вложенность ок)
! skip ; ! auto 2000 ; ! speed 25
*bold* ~italic~ _underline_ [red]..[/red] [gold]..[/gold] [k]..[/k]
```
